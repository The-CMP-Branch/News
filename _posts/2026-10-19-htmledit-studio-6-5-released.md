R-Comp has released HTMLEdit Studio 6.5, a major update to its web development suite that brings compatibility with modern ARMv8 computers and introduces HTML5 features to replace obsolete browser plugins.

The new version focuses on compatibility with current hardware including Raspberry Pi 4 and RK3399-based systems. HTMLEdit is now supplied as a complete suite of programs, with updates across most components of HTMLEdit and the Web Designer's Toolkit.

## New and Updated Tools

WebMapper has been converted from assembly language to C to facilitate easier updates. The HTML-aware spell checker WebSpell now incorporates HTMLEdit's syntax coloring while checking web pages. The older Textures software has been replaced with the full Textures Pro suite in its modern version.

A notable addition to the suite is RISCsurf, intended as a replacement for WebsterXL during page development. Based on NetSurf, RISCsurf implements HTMLEdit's dynamic preview protocols and auto-refresh functionality, allowing the two applications to work together seamlessly. While it can be used for general browsing, RISCsurf is specifically designed to integrate with HTMLEdit and other tools to streamline the web development experience.

RISCsurf includes updated CSS support and JavaScript capabilities, enabling developers to create standards-compliant CSS-based pages. Source code is supplied in accordance with NetSurf's GPL requirements.

## Additional Features

The suite includes various conversion tools for different file types, images, and documents, including support for Ovation Pro and Fireworkz formats. SiteMaster and the Web Designer's Toolkit remain part of the package, with WebsterXL still included for those who prefer it.

New copies of HTMLEdit Studio 6.5 cost £39, while existing HTMLEdit users can upgrade for £20 using the code UPGRADE when ordering through !Store.
