RISC OS Developments has announced the RISC OS Renaissance Project, an umbrella initiative bringing together multiple development efforts aimed at advancing the operating system toward 64-bit capability while continuing to enhance the current 32-bit platform.

The project represents a community-driven approach to OS development, with RISC OS Developments providing resources to support various collaborative efforts. According to the announcement, the Renaissance Project aims to bring new features to RISC OS at a time when significant focus is being placed on the transition to 64-bit architecture.

## Key Goals

The Renaissance Project focuses on several core objectives: converting OS modules from assembly language to C and other high-level languages, field-testing new C code alongside fresh features, and delivering improvements built on top of existing RISC OS 5. The initiative emphasizes the use of modern development tools to accelerate feature delivery.

All work under the Renaissance banner is open source, ensuring the entire RISC OS community can benefit from the developments. Notably, the project requires no additional funding to get started, making it immediately viable.

## First Deliverables

The first tangible results emerged in September 2026 with LanMan98, featuring SMB2/3 support and WebDAV connectivity including PCloud integration. Additional improvements to Draw and Paint applications are also in the pipeline.

Those interested in learning more can watch Andrew Rawnsley's presentation to the Wakefield User Group from September, which introduced the Renaissance Project concept to the community. The initiative marks a significant coordinated effort to modernize RISC OS while maintaining compatibility with existing systems.
