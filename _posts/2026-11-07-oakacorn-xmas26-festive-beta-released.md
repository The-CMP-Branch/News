Paul Emerton of OakAcorn Software has announced the release of several RISC OS 5 applications ready for beta testing ahead of Christmas, with the main offering being !Xmas26 – a festive application that brings a Christmas living room to the desktop.

## !Xmas26 – Christmas on the Desktop

Version 2.47 beta of !Xmas26 provides a Christmas living room environment with carols and an animated scene. Users can follow lyrics on screen, engage with karaoke mode, or try the Dance/Trance mix for a continuous musical set. The application includes editable Maestro scores derived from its compositions, allowing users to explore and modify the music on systems with Maestro installed.

Emerton explained that the project was inspired by fond memories of Carols on the BBC Micro and !PowerCarols on the Archimedes, though !Xmas26 is an independent creation with no endorsement from those earlier developers. The source code for those original programs was not provided to the development tools used.

## Desktop Diversions

Alongside !Xmas26, OakAcorn Software has released several smaller desktop applications:

**Tracks** (v1.2.2) sends a steam, diesel or electric train trundling along the icon bar and into its tunnel.

**Answers** (v1.0.1) poses one question about life, the universe and everything, with the possibility of a Vogon poetry reading for certain responses.

**Penguin Bowl** offers ten frames of bowling with penguins on an icy lane, where users set aim and power before bowling.

**Dual Clock** (v1.1.1) displays an analogue face, digital readout and local date in a single small desktop window.

## Development Approach and Source Availability

Emerton has been open about the development methodology, stating that the projects were assembled with AI assistance alongside human design, specification, curation and peer review. The developer emphasises that comprehensive source documentation, licensing and attribution information is provided for inspection. The code is available for review, and corrections to any errors, omissions or incorrect credits are welcomed at feedback@oakacorn.co.uk.

## Beta Testing Notes

As beta software, the usual caveats apply. The applications are supplied without warranty and should be used at the developer's own risk. Emerton recommends using a spare or test system, or an emulator such as RPCEmu, and keeping backups. The developer notes that bugs may cause crashes or data loss.

Testing has been conducted extensively with positive feedback received, but further testing across different systems is encouraged. Bug reports should include hardware details and RISC OS version. The developer plans to explore compatibility with other RISC OS versions as time permits.

For users running RPCEmu with HostFS, the OakAcorn Software site provides downloads with the `,a91` extension appended to preserve RISC OS archive types when copying files into the HostFS folder.

All applications are available from the [OakAcorn Software website](https://www.oakacorn.co.uk/), with discussion in the [RISC OS Open forum announcement thread](https://www.riscosopen.org/forum/forums/1/topics/20653).
